Terra script fonts: Sarkaz, Sami, Aegir
=======================================

These are the same fonts that Closure's Toolbox Alphabet Generator uses, set up as one font per script.

Sarkaz-EndfieldByButan.ttf / .woff2
  Sarkaz. The original EndfieldByButan by lhclbt, unmodified. Works in any letter case.
  https://github.com/lhclbt/Endfield_Font
  License: CC BY-NC 4.0 (non-commercial use only).

TerraSami-Regular.ttf / .woff2
  Sami. Every letter renders as Sami, whether you type capitals or lowercase.

TerraAegir-Regular.ttf / .woff2
  Aegir. Every letter renders as Aegir, whether you type capitals or lowercase.

Terra Sami and Terra Aegir are split from Samigirian Serif v1.001 by Siphercase, which is built on Elstob
by Peter S. Baker (https://github.com/Siphercase/Samigirian). The original font puts Sami on capital
letters and Aegir on lowercase ones. Here each font maps both cases to one script. Digits and punctuation
are unchanged. OFL reserves the name "Samigirian", so the modified fonts are renamed.
License: SIL Open Font License 1.1 (see OFL.txt).

Sami and Aegir are fan reconstructions, not official Hypergryph material.
